# P4/P5 — L2/L3 thematic curriculum curation

> Executed directly (not full subagent-driven-development with per-task review):
> the classification step was delegated to parallel batch subagents (content
> judgment, not code), the assembly/ordering/regeneration step is mechanical
> and was implemented and verified directly against the pipeline's existing
> hard-fail validation (`validateContent`) as the safety net.

**Goal:** Replace the frequency-chunked "Unit N" placeholders for HSK level 2
(750 words / 63 units) and level 3 (953 words / 79 units) with themed units,
Vietnamese-titled, following the same single-character-before-compound-word
ordering principle already applied to level 1 in P3.

**Spec:** `docs/superpowers/specs/2026-09-12-vietnamese-hanviet-localization-design.md`
(§8, §10 — P4/P5).

## Why this is safe to do as a full reshuffle

`Sentence.unitId` and `GrammarPoint.unitId` are NOT authored — they are
computed by the pipeline (`placement.ts`): a sentence is placed at the
*latest* unit among its words' current unit assignments; a grammar point is
placed at (or spills forward from) the latest unit among its sentences'
placements (L2/L3 use `placeGrammar`, not L1's `placeAuthoredGrammar`).
Reassigning which unit each word belongs to therefore does not require
touching any authored sentence/grammar data — placement recomputes
automatically on every build. `validateContent`'s existing hard-fail rules
(`word-unit`, `unit-empty`, `sentence-order`, `grammar-refs`) also already
guard against coverage gaps, duplicates, and any word used before its own
unit — so a mistake in the reshuffle fails the build loudly rather than
shipping silently.

Known accepted trade-off: a sentence's *pedagogical* placement can end up in
a thematically unrelated unit if its words got bucketed into different
themes (mechanically safe, not perfectly curated) — documented, not fixed,
given P4/P5's stated scope is vocabulary/unit theming, not re-authoring the
939 existing example sentences.

## Method

1. **Classify.** Extract every L2/L3 word (simplified, Vietnamese meaning,
   POS, frequency) and split into batches of ~150. Dispatch one subagent per
   batch (parallel, independent) to assign each word to one of a fixed list
   of 23 Vietnamese theme labels (given verbatim to every batch so labels
   merge consistently across batches without reconciliation).
2. **Aggregate + chunk.** Merge all batch outputs into one word→theme map.
   Group each level's words by theme, preserving original frequency order
   within a theme (frequency order approximates a difficulty gradient).
   Chunk each theme's word list into units of ~12 words (soft target, elastic
   per spec §8), merging an undersized final chunk into the previous one
   (same `minLastUnit` policy as `assignUnits`' frequency fallback).
3. **Fix ordering.** Reuse P3's dependency-fix algorithm
   (`curriculum-order.ts`'s `findOrderViolations` + the same move-to-earliest-
   need-unit technique), applied across the combined L1(frozen)+L2+L3
   sequence: for every compound word whose constituent character is itself a
   course word assigned to a later (or same, later-positioned) unit, move
   that single-character word to the earliest unit that needs it, inserted
   immediately before the first dependent word within that unit. L1 units are
   never modified (already fixed in P3).
4. **Title + write.** Assign sequential unit ids (`l2-u01..`, `l3-u01..`) in
   theme-then-frequency order; title = the theme label, with a numeric suffix
   ("Theme 1", "Theme 2", ...) when a theme spans more than one unit. Write
   `authored/units/level2.json` and `level3.json`.
5. **Regenerate + verify.** Rebuild content, run the full pipeline test suite
   (`validateContent` must pass — this is the hard safety net for coverage/
   duplication/order bugs), extend `curriculum-order-data.test.ts` to cover
   L1+L2+L3 combined (0 violations expected once both levels are done).

## Acceptance

- `pnpm -C packages/content build` succeeds (validateContent passes: no
  missing/duplicate word coverage, no sentence/grammar reference breaks).
- `findOrderViolations` returns `[]` across the whole course (L1+L2+L3).
- Every L2/L3 unit has a Vietnamese title (no "Unit N" placeholders left).
- Full monorepo test suite green (content/web/worker).
